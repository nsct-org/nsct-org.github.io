เว็บไซต์และช่อง YouTube ของ ศนท. · มีผลตั้งแต่ 18 ตุลาคม 2569

เว็บไซต์และช่องนี้คืออะไร

ศูนย์กลางสหภาพนักเรียนนิสิตนักศึกษาแห่งประเทศไทย (ศนท.) หรือ National Student Coalition of Thailand (NSCT) ดูแลเว็บไซต์ nsct-org.github.io และช่อง YouTube "ศนท. - NSCT" เพื่อเล่าประวัติศาสตร์การเมืองและประชาธิปไตยไทย นโยบายนี้อธิบายว่าเราเก็บและใช้ข้อมูลของคุณอย่างไรเมื่อคุณเข้าเว็บไซต์ ดูช่อง หรือติดต่อเรา

สรุปสั้นๆ: เราไม่ได้เก็บข้อมูลส่วนตัวของผู้เข้าชม นอกจากข้อมูลที่คุณส่งมาให้เราเองทางอีเมล

เว็บไซต์

  • ไม่ใช้คุกกี้ และไม่มีระบบติดตามหรือนับสถิติผู้เข้าชม เราไม่รู้ว่าใครเข้าเว็บไซต์
  • เว็บไซต์ฝากไว้กับ GitHub Pages ของบริษัท GitHub ซึ่งอาจบันทึกข้อมูลทางเทคนิค เช่น ที่อยู่ IP เพื่อความปลอดภัยของระบบ ตามนโยบายความเป็นส่วนตัวของ GitHub เราไม่ได้รับข้อมูลนี้
  • ฟอนต์โหลดจาก Google Fonts และภาพปกคลิปโหลดจาก YouTube เบราว์เซอร์ของคุณจึงติดต่อกับเซิร์ฟเวอร์ของ Google เพื่อดึงไฟล์เหล่านี้ ตามนโยบายความเป็นส่วนตัวของ Google
  • ลิงก์ไปเว็บไซต์อื่น เช่น YouTube จะอยู่ภายใต้นโยบายของเว็บไซต์นั้น

ช่อง YouTube

  • YouTube เป็นบริการของ Google การดู กดถูกใจ คอมเมนต์ หรือกดติดตาม อยู่ภายใต้ข้อกำหนดของ YouTube และนโยบายความเป็นส่วนตัวของ Google
  • คอมเมนต์ของคุณเป็นข้อความสาธารณะที่ทุกคนเห็นได้ เราอาจตอบกลับ ปักหมุด หรือลบคอมเมนต์ที่เป็นสแปม หยาบคาย หรือผิดกฎหมาย
  • YouTube แสดงสถิติของช่องให้เราเห็นเป็นตัวเลขรวมเท่านั้น เช่น ยอดวิว ระยะเวลาการดู ประเทศ และช่วงอายุของผู้ชมโดยรวม เราไม่เห็นว่าใครเป็นคนดูคลิปไหน
  • เราใช้สถิติเหล่านี้เพื่อปรับปรุงคอนเทนต์ของช่องเท่านั้น

เมื่อคุณติดต่อเรา

  • ถ้าคุณส่งอีเมลมาที่ nsct.org@gmail.com เราจะได้รับชื่อ อีเมล และข้อความที่คุณเขียน
  • เราใช้ข้อมูลนี้เพื่อตอบกลับและประสานงานในเรื่องที่คุณติดต่อมาเท่านั้น ไม่นำไปเผยแพร่ ไม่ขาย และไม่ส่งต่อให้ผู้อื่นโดยไม่ได้รับอนุญาต
  • แบบฟอร์มในหน้าติดต่อเราไม่ได้ส่งข้อมูลมาที่เราโดยตรง แต่จะเปิดแอปอีเมลในเครื่องของคุณ ข้อความจะถูกส่งก็ต่อเมื่อคุณกดส่งเอง

เด็กและเยาวชน

ผู้ชมของเราหลายคนเป็นนักเรียน เราไม่ได้ตั้งใจเก็บข้อมูลส่วนตัวของผู้ใช้ที่อายุต่ำกว่า 18 ปี หากผู้ปกครองพบว่าบุตรหลานส่งข้อมูลส่วนตัวมาให้เรา ติดต่อเราเพื่อให้ลบได้

สิทธิ์ของคุณ

คุณขอให้เราแจ้งว่าเรามีข้อมูลอะไรของคุณ ขอแก้ไข หรือขอให้ลบอีเมลและข้อมูลที่คุณเคยส่งมาได้ตลอดเวลา ตามพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 โดยส่งอีเมลมาที่ nsct.org@gmail.com
